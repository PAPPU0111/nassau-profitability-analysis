# 🍫 Nassau Candy Profitability Analysis

## 📊 Project Overview
This project analyzes business profitability using real-world retail data. It identifies high-performing products, cost inefficiencies, and regional performance using Python and an AI-powered dashboard.

---

## 🚀 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Profitability & Cost Analysis
- Pareto (80/20) Analysis
- Interactive Streamlit Dashboard
- 🤖 AI-Generated Business Insights

---

## 🧠 Tech Stack
- Python (Pandas, NumPy)
- Matplotlib & Seaborn
- Streamlit
- Data Analytics

---

## 📈 Key Insights
- Top 5 products generate ~80% of profit
- Chocolate division contributes ~93% revenue
- Some products have high cost ratio (>50%)
- Identified low-margin and high-risk products

---

## 🎯 Dashboard Features
- KPI Metrics (Revenue, Profit, Margin)
- Product & Region Filters
- Profitability Charts
- Heatmaps & Trends
- Product Quadrant Analysis
- AI-generated insights
